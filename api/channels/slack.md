# Slack

**Coming soon.** Slack will work the same way as [WhatsApp](/api/channels/whatsapp) — you
connect your own Slack App, KeenVector routes through it. Slack's webhook verification is
structurally different from Meta's (no GET handshake, a timestamp-signed HMAC instead), and
is already supported on the [webhooks](/api/webhooks) side.

Want early access? Talk to your account team.
