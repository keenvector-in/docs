# Recipes

Step-by-step [workflows](/api/workflows) you can build in the console in a few minutes.
Each uses only steps that run today.

| Recipe | Trigger | What it does |
|---|---|---|
| [Forward WhatsApp messages to your team](/api/recipes/forward-whatsapp-to-your-team) | Incoming Message | Thanks the customer and forwards messages about one brand to a team member's WhatsApp |
| [Thank website leads on WhatsApp](/api/recipes/thank-website-leads) | Form Submitted | Sends a thank-you to the lead's phone and alerts your team |
| [Welcome new contacts](/api/recipes/welcome-new-contacts) | Contact Created | Sends a one-time WhatsApp welcome to someone who reaches you for the first time |

All three send WhatsApp messages, so you need WhatsApp connected (see
[WhatsApp](/api/channels/whatsapp)) and, for incoming messages, the webhook set up (see
[Receiving provider webhooks](/api/receiving-webhooks)).
